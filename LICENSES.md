# Software and data licensing

The MPL-2.0 license at the repository root applies to the original maintenance
software and documentation, not to all third-party library data produced by it.
The acquisition policy records an independently reviewed license and attribution
for every upstream. Every package retains its exact original sources, original
license evidence, complete license texts, and a statement that normalization is
a Floe modification. Individual sources remain separate even in the full download.

## KiCad and Espressif

These libraries use CC BY-SA 4.0 with KiCad's design exception. KiCad expressly
distinguishes using a component in an electronic design from redistributing a
library collection. The exception does not exempt redistributed library
collections: original and converted library data retain the applicable CC terms,
attribution and license documents. The exception does not require a user's
electronic design to adopt the library license merely because it uses the data.

Sources: [KiCad library license](https://www.kicad.org/libraries/license/),
[Espressif license](https://github.com/espressif/kicad-libraries/blob/main/LICENSE.md).

## SparkFun

SparkFun's library README declares CC BY 4.0 and permits commercial use. We retain
the original README and common license text, attribute SparkFun and upstream
contributors, and identify normalization as a modification. New per-file or
otherwise conflicting notices require review; the policy is not permission to
remove existing notices.

Source: [SparkFun README](https://github.com/sparkfun/SparkFun-KiCad-Libraries#license).

## LibrePCB

The official LibrePCB library organization uses CC0-1.0. Each enabled repository
is individually pinned and its own `LICENSE.txt` is checked before packaging.
Application-source licensing is separate from library-data licensing.

Source: [LibrePCB licensing](https://librepcb.org/license/).

## Würth Elektronik

The source policy retains the upstream URL as disabled. Its custom terms permit
downloads, designs, modifications and sharing modified models under conditions,
but do not establish a general grant to redistribute the original library as
our own collection. It is excluded from automated redistribution until appropriate
authorization is established. Nothing in this repository changes those terms.

Source: [upstream license terms](https://github.com/WurthElektronik/KiCad-Library/blob/master/License_Terms_WE_KiCad_library.pdf).

## Collection and software boundaries

A separate repository improves provenance and maintenance. The distinction
between independently licensed data and software also applies when they are
distributed together in separate files. Changing repository location does not
change any third-party license obligations. No claim is made that converted
third-party data has become MPL-2.0 software.

Sources: [Creative Commons collection FAQ](https://creativecommons.org/faq/#if-i-create-a-collection-that-includes-a-work-offered-under-a-cc-license-which-licenses-may-i-choose-for-the-collection),
[Mozilla MPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/).
